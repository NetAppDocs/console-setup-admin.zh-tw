= 在NetApp Console中新增資源
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
透過將使用者新增至NetApp Console組織中的專案和資料夾來控制使用者對資源的存取權限。授予專案級使用者存取權限。

資源是指控制台所感知到的實體，例如儲存資源、控制台代理程式或備份和還原工作負載。

您可以在控制台的「資源」頁面中檢視和管理資源。



[[console-resource-types]]
== 控制台資源類型

您可以將多種類型的資源關聯到NetApp Console組織中的專案：

儲存資源:: 儲存資源是組織中最常見的資源類型，包括內部部署儲存系統和雲端儲存系統。將儲存系統新增至 Console 時，需要將其新增至專案。在此之前，Console 會將其標記為未發現，並且不會在 *Resources* 頁面上顯示。
+
--

NOTE: 具有 Org admin 角色的使用者可以將資源新增至資料夾，將資源與專案關聯的任務委派給該資料夾的 Folder 或 project admin。link:task-iam-manage-folders-projects.html#associate-resource-folder["了解如何將資源與資料夾關聯"]。

--
控制台代理:: 如果您使用 Console 代理程式來探索儲存系統，請將該代理程式新增至與儲存系統相同的專案中。這樣，使用者就可以執行代理程式啟用的功能，例如資料服務或 Console 原生儲存管理。您可以從 Console 的 *Agents* 頁面將代理程式新增至專案。link:task-iam-associate-agents.html["了解如何將 Console 代理程式與專案建立關聯"]。
Keystone訂閱:: 如果您的組織擁有 Keystone 訂閱、您可以在 *Resources* 頁面中檢視這些訂閱。您可以將 Keystone 訂閱與專案建立關聯、以便為擁有這些專案權限的成員提供存取權。
備份與還原工作負載:: 備份與還原工作負載也被視為資源。您可以將工作負載與專案建立關聯，為使用者指派存取備份與還原工作負載的權限。例如，將備份與還原工作負載與使用者可存取的專案建立關聯，並授予適當的備份與還原角色，即可為使用者指派該工作負載的存取權限。




[[view-the-resources-in-your-organization]]
== 查看組織中的資源

您可以查看與您的組織相關的已發現和未發現的資源。系統會尋找儲存資源，並將其標記為未發現，直到您將其新增至控制台為止。


NOTE: 控制台會將Amazon FSx for NetApp ONTAP資源從「資源」頁面中排除，因為使用者無法將其與角色關聯。您可以在「系統」頁面或「工作負載」中查看這些資源。

.步驟
. 選擇*管理>身分和存取*。
. 選擇*資源*。
. 選擇*進階搜尋和過濾*。
. 利用現有選項尋找資源：
+
** *按資源名稱搜尋*：輸入文字字串並選擇*新增*。
** *平台*：選擇一個或多個平台，例如 Amazon Web Services。
** *資源*：選擇一個或多個資源，例如Cloud Volumes ONTAP。
** *組織、資料夾或專案*：選擇整個組織、特定資料夾或特定專案。


. 選擇*搜尋*。




[[associate-a-resource-with-folders-and-projects]]
[[associate-resource]]
== 將資源與資料夾和項目關聯

將資源關聯到資料夾或項目，使其可供具有該資料夾或項目權限的成員使用。

.步驟
. 從「資源」頁面，導覽到表中的資源，選擇image:icon-action.png["三個並排的點組成的圖標"]然後選擇*關聯到資料夾或項目*。
. 選擇一個資料夾或項目，然後選擇*接受*。
. 若要關聯其他資料夾或項目，請選擇*新增資料夾或項目*，然後選擇該資料夾或項目。
+
請注意，您只能從您擁有管理員權限的資料夾和項目中進行選擇。

. 選擇*關聯資源*。
+
** 如果您將資源與項目關聯，則擁有這些項目權限的成員現在可以從控制台存取該資源。
** 如果您將資源與資料夾關聯，則_資料夾或專案管理員_現在可以存取該資源並將其與資料夾內的項目關聯。link:task-iam-manage-folders-projects.html#associate-resource-folder["了解如何將資源與資料夾關聯"]。




.完成後
如果您使用控制台代理程式發現資源，請將控制台代理程式與專案關聯以授予存取權限。否則，沒有「組織管理員」角色的成員將無法存取控制台代理程式及其相關資源。

link:task-iam-associate-agents.html["了解如何將控制台代理與資料夾或項目關聯"] 。

== 查看與資源關聯的資料夾和項目

您可以查看與特定資源關聯的資料夾和項目。


NOTE: 如果您需要了解哪些組織成員有權存取該資源，您可以link:task-iam-manage-folders-projects.html#view-associated-resources-members["查看有權存取與資源關聯的資料夾和項目的成員"]。

.步驟
. 從「資源」頁面，導覽到表中的資源，選擇image:icon-action.png["三個並排的點組成的圖標"]然後選擇*查看詳細資訊*。


以下範例顯示了與一個項目關聯的資源。

image:screenshot-iam-resource-details.png["資源詳細資訊頁面的螢幕截圖，顯示與組織下屬專案關聯的資源。"]


NOTE: 要查看哪些組織成員有權存取該資源，link:task-iam-manage-folders-projects.html#view-associated-resources-members["查看有權存取關聯資料夾和項目的成員"] 。

== 從資料夾或項目中刪除資源

若要從資料夾或項目中刪除資源，請刪除其關聯。這樣可以防止成員管理該資料夾或專案中的資源。


NOTE: 若要從整個組織中刪除已發現的資源，請前往「系統」頁面並刪除該系統。

.步驟
. 從「資源」頁面，導覽到表中的資源，選擇image:icon-action.png["三個並排的點組成的圖標"]然後選擇*查看詳細資訊*。
. 若要從資料夾或項目移除資源，請選擇 image:icon-delete.png["垃圾桶的圖標"] 在資料夾或項目旁邊。
. 選擇“刪除”以移除關聯。
