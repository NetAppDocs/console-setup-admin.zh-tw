= 開始使用NetApp Console助手
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
如果您是首次使用NetApp Console(SaaS) 並擁有組織管理員角色的用戶，則可以使用控制台助理來引導您完成初始設定程序。此助手可協助您新增NetApp支援網站 (NSS) 帳戶、新增控制台代理程式、新增叢集以及新增授權或訂閱，以便更輕鬆地開始管理您的資料。



[[required-roles-to-access-the-console-assistant]]
== 存取控制台助手所需的角色

控制台助理僅對具有組織管理員角色的使用者可用。

預設情況下，對於具有組織管理員角色的首次用戶， NetApp Console會在主頁上顯示控制台助理。在您完成建立控制台代理程式和新增系統的必要任務之前，它將一直可用。

使用助理來完成這些任務，為您的 NetApp Console 環境提供最基本的設定：

* 新增NetApp支援網站 (NSS) 帳戶。
+
link:task-adding-nss-accounts.html["了解如何新增 NSS 帳戶"]。

* 透過部署控制台代理程式連接到您的儲存環境。
+
link:task-install-agent-on-prem.html["了解如何在本機安裝控制台代理程式。"]

* 透過新增或發現叢集來管理儲存系統
* 新增市場訂閱或 PAYGO 授權。
+
link:https://docs.netapp.com/us-en/console-licenses-subscriptions/index.html["了解如何新增授權和訂閱"^]。

* 查看數據服務資訊。
