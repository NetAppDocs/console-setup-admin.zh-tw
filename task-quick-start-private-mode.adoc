= 私有模式下 NetApp Console 快速入門
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以將 NetApp Console 安裝在內部部署或安全的雲端環境中。私有模式通常用於沒有網際網路連線的內部部署環境以及安全的雲端區域，包括 https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^]、 https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^]和 https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"] link:task-prepare-private-mode.html["準備部署"]
[role="quick-margin-list"]
. 準備一個符合 CPU、RAM、磁碟空間、容器編排工具等要求的專用 Linux 主機。
. 設定可存取目標網路的網路。
. 對於雲端部署，請在雲端供應商中設定權限，以便在安裝軟體後將這些權限與 Console 代理程式建立關聯。


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"] link:task-install-private-mode.html["部署控制台代理"]
[role="quick-margin-list"]
. 在您自己的 Linux 主機上安裝 Console 代理程式。
. 開啟網頁瀏覽器並輸入 Linux 主機的 IP 位址，即可設定 NetApp Console。
. 對於雲端部署，請向 NetApp Console 提供您先前設定的權限。
