= 登入NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
註冊NetApp Console後，您可以從基於 Web 的控制台登錄，開始管理您的資料和儲存基礎架構。

註冊後，您的 Console 組織管理員必須先將您的使用者帳戶新增至組織，您才能存取任何資源。如果您登入後看不到任何資源，請聯絡您的組織管理員。link:task-user-settings.html#contact-admin["請聯絡您的組織管理員"].

.步驟
. 導覽至 NetApp Console URL。URL 取決於貴組織使用的 Console 模式：
+
** *標準模式*：開啟網頁瀏覽器並前往 https://console.netapp.com["NetApp Console"]
** **受限模式或私有模式**：開啟網頁瀏覽器，造訪 Console 代理安裝所在的 IP 位址。


. 在*登入*頁面上，輸入與您的登入關聯的電子郵件地址。
. 根據與您登入相關的驗證方法，系統會提示您輸入憑證。
+
** 您現有的NetApp支援網站 (NSS) 憑證
** 使用您的電子郵件地址和密碼的NetApp Console帳戶
** 如果您的管理員已為您的組織設定身分聯合，則為聯合連線
