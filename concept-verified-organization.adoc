= 瞭解在 NetApp Console 中經過驗證的組織
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
經過驗證的組織會將您在 NetApp Console 中的組織與您的 NetApp 業務帳戶身分（例如 CMAT ID）關聯起來。這有助於 Console 在各個 NetApp 系統中應用一致的組織身分和治理模型。



== 為何要驗證您的組織

驗證您的組織身份可以幫助您：

* 將您的 Console 組織與您的 NetApp 業務帳戶身分保持一致。
* 提高管理、報告和支援工作流程的一致性。
* 減少團隊跨多個 NetApp 服務工作時的歧義。
* 支援依賴可信任組織身分的治理控制。




== 驗證後會有哪些變化

您的組織通過驗證後：

* 該組織與 NetApp 企業帳戶身分相關聯。
* NetApp Console 可以將該組織身分視為業務級對應的權威身分。
* 如果某些組織設定檔變更由來源系統管理，則在 Console 中可能會受到限制。




== 在您驗證之前

在驗證您的組織之前，請確認以下事項：

* 您擁有貴組織所需的管理角色。
* 您已具備驗證所需的組織詳細資訊。
* 您已與您的 NetApp 客戶團隊協調，確認是否需要驗證業務帳戶對應關係。
