[[console-agent-4-13-0]]
=== Console 代理 4.13.0

4.13.0 版本同時支援標準模式和受限模式。

此版本的 Console 代理程式包含安全性改進和問題修復，以及以下新功能。當您使用 ISO 將部署於 vCenter 的 Console 代理程式升級至 4.13.0 時，請確保在升級完成後重新啟動虛擬機器。虛擬機器可能會自動重新啟動。



==== 部署 Console 代理程式時自動建立 AWS 部署角色

您不再需要在開始之前建立 IAM 角色，以在 AWS 中部署 Console 代理程式。NetApp Console 可以為您建立該角色。link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-console.html["了解如何從主控台在 AWS 中部署主控台代理程式"^]



[[netapp-console-administration]]
=== NetApp Console管理

此版本包含安全性改進和問題修復，以及以下新功能。



==== 指派 Cloud Volumes ONTAP 貢獻者角色

現在您可以指派 Cloud Volumes ONTAP 參與者角色，讓成員能夠廣泛存取以管理 Cloud Volumes ONTAP 系統，但不允許他們刪除系統、Volume、聚合或複寫關係。link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-cvo-roles.html["深入瞭解 Cloud Volumes ONTAP 的角色型存取"^]。
