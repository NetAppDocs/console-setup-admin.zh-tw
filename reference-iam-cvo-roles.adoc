= NetApp Console 中的 Cloud Volumes ONTAP 存取角色
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以為使用者指派下列角色，以便他們在控制台中存取 Cloud Volumes ONTAP。Cloud Volumes ONTAP 角色可讓您靈活地為使用者指派特定角色，以滿足他們在組織內需要完成的任務。角色分配方式取決於您自身的業務和儲存管理實務。

Cloud Volumes ONTAP 使用下列角色：

* *Cloud Volumes ONTAP admin*：提供對所有 Cloud Volumes ONTAP 操作的完全存取。
* *Cloud Volumes ONTAP operator*：執行重要的儲存作業，例如探索和管理 Cloud Volumes ONTAP 系統，包括新增磁碟區、集合體、快照和複寫，修改部分組態，以及升級 Cloud Volumes ONTAP 版本。
* *Cloud Volumes ONTAP 檢視器*：提供對 Cloud Volumes ONTAP 資訊的唯讀存取。此角色無法執行任何主動操作。某些包含組態資訊的索引標籤和畫面可能對檢視器不可用。


如需瞭解所有 NetApp Console 存取角色的詳細資訊，請參閱 link:reference-iam-predefined-roles.html["存取角色"]。



[[how-role-changes-take-effect]]
== 角色變更如何生效

Cloud Volumes ONTAP 透過使用每個角色指派的本機快取來強制執行角色型存取控制 (RBAC)。快取每小時自動重新整理一次。如果角色為新指派或已變更，變更最多可能需要一小時才能生效。重新整理完成後，主控台將啟用該角色所允許的工作流程。


NOTE: 首次部署 Console 代理程式或將現有 Console 代理程式升級至 Console 4.9.0 或更高版本時，Console 會執行一次性初始化過程，將 Cloud Volumes ONTAP 角色指派給組織中的現有使用者。此過程可能需要長達 30 分鐘才能完成。
