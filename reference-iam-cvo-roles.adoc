= NetApp Console 中的 Cloud Volumes ONTAP 存取角色
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以將下列角色指派給使用者，以便他們在 NetApp Console 中存取 Cloud Volumes ONTAP。

* *Cloud Volumes ONTAP admin*：提供對所有 Cloud Volumes ONTAP 操作的完全存取。
* *Cloud Volumes ONTAP 營運者*：執行重要的儲存設備操作，例如發現與管理 Cloud Volumes ONTAP 系統，包括新增磁碟區、集合體、快照與複寫，修改部分組態，以及升級 Cloud Volumes ONTAP 版本。
* *Cloud Volumes ONTAP 檢視器*：提供對 Cloud Volumes ONTAP 資訊的唯讀存取。此角色無法執行任何主動操作。某些包含組態資訊的索引標籤和畫面可能對檢視器不可用。


link:reference-iam-predefined-roles.html["了解訪問角色"] 。

在包含系統的組織、資料夾或專案層級指派 Cloud Volumes ONTAP 角色。平台角色可讓使用者管理 NetApp Console 資源，而 Cloud Volumes ONTAP 角色可讓使用者管理 Cloud Volumes ONTAP 系統。如需規劃角色指派的指引，請參閱 link:task-cvo-rbac-setup.html#plan-cloud-volumes-ontap-role-assignments["為 Cloud Volumes ONTAP 設定角色型存取"]。



[[role-migrations-for-existing-users]]
== 現有使用者的角色移轉

當您將主控台代理程式升級至 4.9.0 或更新版本時，主控台會根據現有使用者的平台角色，為其指派額外的 Cloud Volumes ONTAP 角色。


NOTE: 當現有的 Console 代理程式升級至 Console 4.9.0 或更新版本時，Console 會執行一次性的初始化程序，將 Cloud Volumes ONTAP 角色指派給組織中的現有使用者。此程序最多可能需要 30 分鐘才能完成。若要審查及調整已初始化的角色，請參閱 link:task-cvo-rbac-setup.html#review-roles-after-upgrading-the-console-agent["升級 Console 代理程式後審查角色"]。

下列對應僅適用於此一次性移轉程序。

[cols="50,50"]
|===
| 現有平台角色 | 在種子產生期間指派 Cloud Volumes ONTAP 角色 


| 超管理員 | Cloud Volumes ONTAP 管理員 


| 組織管理員 | Cloud Volumes ONTAP 管理員 


| 聯盟管理員 | Cloud Volumes ONTAP 管理員 


| 資料夾或專案管理員 | Cloud Volumes ONTAP 管理員 


| 超觀眾 | Cloud Volumes ONTAP 檢視器 


| 組織檢視器 | Cloud Volumes ONTAP 檢視器 


| 聯邦檢視器 | Cloud Volumes ONTAP 檢視器 


| 資料夾或專案檢視器 | Cloud Volumes ONTAP 檢視器 


| 任何其他平台角色 | Cloud Volumes ONTAP 檢視器 
|===
控制台會將 Cloud Volumes ONTAP 角色指派到與現有平台角色相同的層級。這些對應不適用於新的角色指派。若要審查和調整已初始化的角色，請參閱 link:task-cvo-rbac-setup.html#review-roles-after-upgrading-the-console-agent["升級 Console 代理程式後審查角色"]。


NOTE: 目前已知問題導致 *組織檢視者* 和 *Cloud Volumes ONTAP 檢視者* 角色組合無法在組織範圍內正常運作。請使用 *組織管理員* 或 *資料夾或專案管理員* 角色作為臨時解決方案。



[[how-role-changes-take-effect]]
== 角色變更如何生效

最多等待一小時，讓新的或更新的角色指派生效。Cloud Volumes ONTAP 每小時會重新整理角色指派。
