= NetApp Console 統一儲存管理
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console 可協助您管理和保護所有雲端和本機系統中的資料。它包含各種工具，可確保您的資料安全可靠地運作。

您可以將 Console 當作軟體即服務 (SaaS) 應用程式使用，也可以將其安裝在雲端或本機環境中（受限模式或私有模式）。每種模式支援不同的功能集和安全要求。

NetApp Console 可與您部署在環境中的 Console 代理程式搭配使用，以管理資源並協調本地和雲端環境中的流程。



== 選擇如何存取 NetApp Console

要開始使用 NetApp Console，您可以註冊 SaaS 應用程式（標準模式）、將其安裝在雲端（受限模式）或本機（私有模式）。部分功能在受限模式或私有模式下不可用。

link:concept-modes.html["了解有關部署模式的更多信息"] 。



== 使用 Console 代理擴充 Console 功能

Console 代理程式是輕量級軟體元件，可提供與 NetApp Console SaaS 應用程式和基於雲端的 API 的連接，從而實現進階功能和資料服務。

在受限或私有模式下，請在雲端或內部部署環境中安裝 Console 代理程式，以存取 NetApp Console 應用程式。您需要部署其他代理程式，以支援需要直接連線至 NetApp Console 及其 API 的功能。

link:concept-agents.html["了解有關控制台代理的更多信息"] 。



== 在 NetApp Console 中管理使用者存取權限與許可

NetApp Console 提供身分和存取管理（IAM）功能，以增強資料基礎架構的安全性和控制力。圍繞組織角色和職責組織儲存和資料服務，以降低未經授權存取的風險，同時保持營運效率：

* 頂級 _organization_ 可讓您授予和撤銷對整個基礎架構中儲存系統和專案的存取權限
* _Folders_ 功能可讓您根據業務功能或合規性要求將儲存資源和專案分組在一起
* _Projects_ 可讓您控制哪些團隊可以存取特定的儲存系統、磁碟區和資料服務
* _基於角色的存取控制（RBAC）_可讓您為不同層級的團隊成員授予儲存管理權限，從而可以在不授予過多存取權限的情況下委派任務


link:concept-identity-and-access-management.html["了解有關NetApp Console中的 IAM 的更多信息"]



== NetApp Console 的安全性和合規性

啟用單一登入（SSO）等安全性和合規性功能，以控制對儲存和資料服務的存取。擁有組織管理員角色的使用者預設可以設定唯讀模式，使用者必須申請提升的權限才能變更儲存系統和使用資料服務。您也可以使用 NetApp Console 監控儲存管理和使用者活動。NetApp Console 已通過 SOC 2 Type 2 認證，並可 NetApp 向客戶提供 SOC 2 報告。

https://www.netapp.com/company/trust-center/compliance/soc-2/["查看 NetApp 的 SOC 2 報告"^]



== NetApp Console 功能和支援的儲存

NetApp Console 支援本機和雲端環境中的各種儲存類型、功能和資料服務。使用 Console 管理您的儲存系統，監控其運作狀況和效能，並啟用資料服務來保護和最佳化您的資料。

=== NetApp Console 中的儲存管理和健全狀況服務

NetApp Console 透過單一介面提供 NetApp 儲存基礎架構的統一管理。

在 Console 中，_Systems_ 代表您已發現或已部署的儲存空間。您可以直接在 Console 中管理儲存卷，也可以開啟系統的管理介面以取得更多選項。

image:screenshot-canvas.png["控制台截圖，顯示了多個系統。選取其中一個選項，即可啟用NetApp資料服務，或選擇「進入系統」來管理儲存。"]

除了儲存管理之外，還可以使用基礎架構服務來監控和管理所有環境中的儲存基礎架構。

健康與效能監控:: 查看儲存系統運作狀況和效能的儀錶板，並在問題造成嚴重後果之前收到警示以進行修復。
Licenses and subscriptions:: 管理和監控您的許可證和訂閱。
生命週期規劃:: 找出空間不足的叢集，並根據需要增加容量或移動資料。
NetApp數位顧問 (Active IQ):: 使用預測分析和主動支援來優化您的資料基礎架構。
軟體更新:: 實現 ONTAP 升級的評估、規劃和完成自動化。
儲存警報:: 查看與ONTAP環境中的容量、可用性、效能、保護和安全性相關的問題。
系統頁面:: 在一個位置查看所有儲存系統，並快速存取其管理介面。直接從 Systems 頁面拖放即可啟用資料服務。
永續性儀表板:: 分析儲存系統的可持續性。




=== NetApp Console 中的資料安全和保護服務

利用內建資料服務保護關鍵資料並最佳化儲存效率。

NetApp Backup and Recovery:: 備份和還原雲端及內部部署資料。需要訂閱。
NetApp Copy and Sync:: 在內部部署和雲端資料存放區之間同步資料。
NetApp Disaster Recovery:: 使用 VMware Cloud on Amazon FSx for ONTAP 作為災難復原站台，保護內部部署 VMware 工作負載。需要訂閱。
NetApp Ransomware Resilience:: 偵測可能導致勒索軟體攻擊的異常情況。保護並恢復工作負載。需要訂閱。
NetApp Replication:: 在儲存系統之間複製資料以支援備份和災難復原。




=== NetApp Console 中的成本和合規性管理服務

追蹤所有系統中的合約狀態，以改善成本管理、法規遵循和採購決策。

自動化中心:: 使用腳本解決方案自動設定和連接 NetApp 產品和服務，以實現更流暢、更一致的操作。
NetApp Cloud Tiering:: 將您的內部部署 ONTAP 儲存設備擴充至雲端，以實現成本最佳化和資料生命週期管理。
NetApp Data Classification:: 讓您的應用程式資料和雲端環境做好隱私準備，以符合資料隱私法規。訂閱即可免費使用。
NetApp Volume Caching:: 建立可寫入快取磁碟區，以加快資料存取速度或將流量從存取頻繁的磁碟區中卸載，從而提高效能和成本效益。
NetApp工作負載:: 使用 Amazon FSx for NetApp ONTAP 設計、設定及操作關鍵工作負載，以優化特定應用程式的效能和成本。




=== NetApp Console 成本

NetApp 不會對 Console 收費。當您部署 Console 代理程式或在雲端使用受限模式時，會產生費用。某些 NetApp 資料服務也會產生相關費用。https://bluexp.netapp.com/pricing["了解NetApp數據服務定價"^]
